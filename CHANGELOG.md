# Changelog

All notable changes to Nightyard are documented in this file.

## [0.1.0] - 2026-10-31

First public release.

### Features

- Sleepy built in: give it a goal and a time budget, and it works through it unattended (Opus, Codex, or both as a team), ending with one readable report and a note in your vault
- Wakey v2 (beta): an autonomous supervisor that keeps a Claude Code session moving while you're away, survives restarts, and stops itself on caps or repeated errors
- Live agent & knowledge graph in 2D or 3D: click a session bubble to jump into it, click a note in your Obsidian vault to launch an agent, Wakey or Sleepy from it
- Counsel of Personalities: three team members debate a question, then an adjudicator gives a verdict
- Multi-session workspace: kanban board, swarm mode, cost and context tracking, session inspector, session resume, embedded browser, P2P session sharing and an AI readiness score
- Tab detach and multiple windows, kept in sync
- Providers: Claude Code, Codex (with multiple accounts), Gemini, Kimi and Copilot

### Notes

- Builds are unsigned and have no update feed: download new versions from the Releases page
